# Luis Martinez Barraza — Página personal

Sitio estático listo para GitHub Pages.

## Publicar
1. Crea un repositorio en GitHub.
2. Sube `index.html` y la carpeta `assets/` manteniendo la estructura.
3. En **Settings → Pages**, selecciona **Deploy from a branch**.
4. Elige la rama `main` y la carpeta `/ (root)`.
5. Guarda los cambios.

La página no requiere frameworks ni proceso de compilación.
